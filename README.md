Habit Tracker
Project Overview

Habit Tracker is a simple browser-based web application that helps users create and track daily habits. Users can add habits, mark them as completed, monitor streaks, delete habits, and view an overall progress summary.

The application runs entirely in the browser and does not require a server, database, or external framework.

Features
Add new habits
Form validation
Track daily completion status
Automatic streak counting
Delete habits
Progress summary dashboard
Responsive and beginner-friendly design
Technologies Used

HTML5
CSS3
JavaScript (ES6)
Habit Object Structure

Each habit is stored as an object in an array:

{
  id: 12345,
  name: "Drink Water",
  category: "Health",
  target: 7,
  streak: 0,
  doneToday: false
}

Validation Rules
Habit name must contain at least 3 characters.
Target days must be a whole number between 1 and 7.
A category must be selected.
How to Run
Download or clone the project.
Open the project folder in VS Code.
Open the index.html file in your browser.
Start adding habits and tracking progress.
